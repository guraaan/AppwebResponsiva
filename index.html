Lo que el despacho ya hace, ahora más claro

Conservamos las funciones del sistema original y las presentamos con una interfaz pensada para trabajar horas sin cansar la vista.

Expedientes

Cada abogado crea y consulta sus propios expedientes con un código único, ordenados por fecha.

Clientes y deudas

Dentro de cada expediente se registran los clientes, los montos adeudados y su historial.

Pagarés imprimibles

Genera el documento con formato limpio para imprimir y firmar en segundos.

Permisos por rol

El administrador autoriza o retira el acceso a cada abogado con un solo botón.

Del alta al pagaré en cuatro pasos

El flujo sigue el orden real del trabajo de un abogado.

  1. Inicia sesiónAccede con tu cuenta; si aún no estás autorizado, puedes consultar pero no crear.
  2. Abre un expedienteRegistra el código del caso, por ejemplo EXP-2026-A.
  3. Agrega cliente y deudaCaptura los datos y el monto adeudado.
  4. Imprime el pagaréDescarga o imprime el documento listo para firma.
